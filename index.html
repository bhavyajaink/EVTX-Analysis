1. The big picture of the file

EVTX file = File header (4096 bytes) + Chunks (65536 bytes each). Inside every chunk: a 512-byte chunk header, then the event records, then unused space.

Chunk offset calculator   chunk number:

Formula: offset = 4096 + (chunk number × 65536). File size = (chunks × 65536) + 4096.

Key things to remember

• Everything is little-endian: 0x1000 as a 4-byte value is stored as 00 10 00 00.
• Time values are FILETIME: 100-nanosecond ticks since 1 January 1601 (UTC).
• Strings are UTF-16LE: "A" = 41 00.

2. File header (first 128 bytes)

The remaining 3968 bytes are zeros. The checksum is a real CRC-32 calculated over the first 120 bytes.

Both the records checksum and the header checksum are calculated live. Header checksum = CRC32(bytes 0 to 120 + bytes 128 to 512).
